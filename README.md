# AI System Design Generator

An AI-powered tool that generates scalable system architecture diagrams from natural language prompts.

---

## Features

- Generate system designs (Netflix, Uber, Chat apps, etc.)
- Interactive diagram visualization (React Flow)
- Click nodes to explore components
- Backend powered by LLM (Groq/OpenAI)
- PostgreSQL for storing designs

---

## Tech Stack

### Frontend
- React (Vite)
- React Flow
- Axios

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- LLM (Groq/OpenAI)
